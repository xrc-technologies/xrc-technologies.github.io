# 100km+ NOVALINK Setup
{: .d-inline-block }

Introduction
{: .fs-6 .fw-500 }

This guide will show you how to get the maximum range out of the NOVALINK 433MHz mLRS Radio System.

With careful attention to the RF environment, antenna placement/tuning, and geographic planning, ranges of 100km+ can be readily achieved.
